VisionGuard AI is an intelligent CCTV analytics platform that transforms traditional surveillance cameras into AI-powered security systems.



Built using Computer Vision, Person Intelligence, Retrieval-Augmented Generation (RAG), and Large Language Models (LLMs), VisionGuard AI helps security teams monitor people, detect suspicious behavior, manage incidents, and interact with surveillance data using natural language.



\---



\## 🚀 Key Features



\### 👤 Person Intelligence

\- Persistent visitor profiles

\- Visit history

\- Person statistics

\- Risk level assessment

\- Person timeline



\### 🎯 AI Video Analytics

\- Real-time person detection (YOLO11)

\- Person tracking

\- Loitering detection

\- Event detection

\- Video evidence recording



\### 🤖 AI Assistant

\- Intelligent CCTV event search

\- Incident investigation
